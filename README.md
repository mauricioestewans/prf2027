# PRF 2027 — Kit de Estudos

Ferramentas de estudo para o concurso da **Polícia Rodoviária Federal (PRF)**, no formato da banca **Cebraspe** (Certo/Errado).

> **Observação:** os PDFs do curso (material protegido por direitos autorais) **não** fazem parte deste repositório — ficam apenas no armazenamento pessoal.

## Conteúdo

| Arquivo | O que é |
|---|---|
| [`index.html`](index.html) | Página inicial com atalhos para tudo |
| [`quiz-verdadeiro-falso.html`](quiz-verdadeiro-falso.html) | Quiz Verdadeiro/Falso das 15 matérias + Simulado estilo prova + **modo Simulado cronometrado** com nota no critério Cebraspe (acertos − erros). Banco de ~350 questões com sorteio aleatório por rodada. |
| [`treino-redacao.html`](treino-redacao.html) | Treino de redação: sorteia o tema, você escreve e a página corrige dando **nota de 0 a 1000** por competência e dicas. *(A correção automática só funciona aberta dentro do Claude, logado.)* |
| [`rotina-diaria.html`](rotina-diaria.html) | Rotina diária de estudos pensada para TDAH (blocos curtos, rotação de foco, repetição espaçada). |
| [`flashcards-transito.html`](flashcards-transito.html) | Flashcards de Legislação de Trânsito (versão só de trânsito). |
| [`Legislacao_Transito_Anki.txt`](Legislacao_Transito_Anki.txt) | Baralho de flashcards de Trânsito para importar no Anki (separado por Tab). |
| [`ferramenta-download-materiais.js`](ferramenta-download-materiais.js) | Script para baixar os materiais do curso (rodar no console do navegador, logado no site do curso). |

## Como usar

Abra os arquivos `.html` direto no navegador (dois cliques).

- **Quiz:** escolha a matéria, o número de questões e responda. No modo **Treino** a correção aparece na hora; no modo **Simulado**, só no fim, com a nota.
- **Redação:** escreva e clique em *Corrigir*. A correção por IA requer abrir a página pela versão publicada no Claude.
